## 1. 土台：曲線上の点は「群 (group)」をなす

Ed25519 の核心。**曲線の式を満たす点 `(x, y)` を全部集めた集合に「加算」を1つ定義すると、それが数学的な"群"になる。**

群であるとは、ざっくり次が成り立つこと:

- **閉じている** … 点 + 点 = また曲線上の点（外に出ない）
- **単位元がある** … 足しても相手を変えない「0 にあたる点」が存在する
- **逆元がある** … 各点 P に `P + (−P) = 単位元` になる相手がいる
- **結合則** … `(P+Q)+R = P+(Q+R)`

この「点の足し算」が署名の全ての土台。足し算が閉じているからこそ `a·B`（秘密鍵 × 基点）が意味を持つ。
今回はこの足し算と、その繰り返し（スカラー倍）を作る段。

## 2. 最重要の誤解ポイント：「点の加算」は座標の足し算ではない

`add(P, Q)` は `(x1+x2, y1+y2)` **ではない**。全くの別物。
点の加算は「曲線の構造から決まる、専用の計算式」で定義される。Edwards 曲線では:

```
x3 = (x1·y2 + x2·y1) / (1 + d·x1·x2·y1·y2)
y3 = (y1·y2 + x1·x2) / (1 − d·x1·x2·y1·y2)
```

- 割り算 `/` は体の逆元（`feInv`）を掛けること。**field 段の feInv がここで効く。**
- なぜこの式か、を今すぐ導出できる必要はない。**「加算は式で定義された演算」と割り切って、
  まず式を写して onCurve が閉じることを確認する**のが今回の学習ライン。導出は後で戻れる。

## 3. Ed25519 が Edwards 曲線を使う理由：「完全な」加算則

- 教科書でよく出る Weierstrass 形（`y²=x³+…`）は、加算に**場合分けが必要**
  （P=Q の倍加、片方が単位元、で別式）→ バグの温床。
- Ed25519 のねじれ Edwards 曲線 `−x²+y² = 1+dx²y²` は、`d` が平方非剰余に選ばれているおかげで:
  - **上の1本の式が、あらゆるケースで正しく動く**（倍加も単位元絡みも同じ式）
  - 分母が 0 にならない（いつでも割り算できる）
- これを **完全 (complete) な加算則** と呼ぶ。**だから `add` に if 分岐を書かなくていい**（倍加 `add(P,P)` も同じ関数でよい）。この曲線を選んだ最大の理由の一つ。

## 4. 単位元と逆元（具体的に何か）

- **単位元 = `(0, 1)`**。「点の世界の 0」。
  式に入れると成立（`−0+1 = 1+0`）し、加算式に `Q=(0,1)` を入れると `x3=x1, y3=y1`（相手が変わらない）。
- **P=(x, y) の逆元 = `(−x, y)`**。x の符号反転（体では `p−x`）。
- テストで `add(P, identity)==P` や `add(P, negate(P))==identity` を確認する土台になる。

## 5. スカラー倍 = 加算の繰り返し

`scalarMul(k, P)` は **P を k 回足す**:

```
scalarMul(3, P) = P + P + P
```

- Ed25519 の k は 256bit の巨大数なので、素朴な k 回ループは終わらない。
  実務では **double-and-add**（k を2進で見て「2倍」と「足す」を組み合わせ `O(log k)` に）。
- 学習優先なら **まず素朴版（小さい k で正しさ確認）→ 後で double-and-add に置換** で構わない。
  成功条件 `scalarMul(2,B)==add(B,B)` は k=2 なのでどちらでも通せる。

## 6. 頭に入れる「定数」

| 記号 | 何か | 使う場面 |
|------|------|----------|
| `p = 2²⁵⁵−19` | 体の法（定義済み） | 全計算 |
| `d = −121665/121666 mod p` | 曲線の形を決める定数 | onCurve, add |
| `B`（基点, 既知の (x,y)） | 群の"生成元"。全ての鍵はこの点のスカラー倍 | 成功条件, 後で鍵生成 |
| `L`（基点の位数 ≒ 2²⁵²） | B を L 回足すと単位元に戻る数 | **署名の段**で使う。今回は名前だけ |

## 進め方（TDD・TODO.md の子タスク順）

1. **`d` と 基点 `B` を定義**（`d = −121665 · feInv(121666)`、B は RFC 8032 の既知値）
2. **`onCurve(P)`** … テスト: `onCurve(B)` true / `(0,1)` true / 外れ点 false。d・B の検算も兼ねる
3. **`add(P, Q)`** … テスト: `add(P, identity)==P` / `add(B,B)` が onCurve / `add(P,Q)==add(Q,P)`
4. **`scalarMul(k, P)`** … テスト: `scalarMul(2,B)==add(B,B)`（成功条件）/ `scalarMul(1,B)==B` / `scalarMul(0,B)==identity`
5. **仕上げ** … 成功条件を緑にして子タスクを `[x]`、コミット → PR

### 実装メモ（着手時に決める小さいこと）
